# Licensed webfonts

Two commercial faces, copied from the kits in the owner's Downloads:

- **KH Teka Mono Regular** (KH Type) - every number in the product. Prices,
  percentages, countdowns and payouts are read as columns, so they get a
  monospace with true tabular figures. Licensed kit, not the TRIAL cut that
  SolPump currently bundles.
- **Kern Standard Regular** (Pizzatypefaces, via MyFonts kit 3867246) - UI and
  headings.

Both are **per-licence webfonts, not redistributable**. The MyFonts notice is
explicit that parties other than the licensed website owner may not use them.
Before this is deployed anywhere public, check the EULA covers the domain it
is served from (`KH Type EULA.pdf` ships alongside the KH Teka kit).

Only the Regular weight of each is licensed here, so both are declared as a
single 400 weight. Weight contrast has to come from size and colour, not from
a heavier cut, or the browser will synthesise a fake bold.
